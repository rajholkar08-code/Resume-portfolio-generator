# Resume Portfolio Generator

A Python-based AI project that converts a resume into a professional portfolio website using the Gemini API.

## Features

* Resume Parsing
* AI-powered Information Extraction
* JSON Generation
* Automatic HTML Portfolio Creation
* CSS Styling

## Technologies Used

* Python
* Gemini API
* HTML
* CSS
* JSON

## Workflow

Resume → Gemini API → JSON → Portfolio Website

## How to Run

1. Install dependencies
2. Add Gemini API Key in `.env`
3. Run:

```bash
python main.py
```

4. Open `portfolio.html`
